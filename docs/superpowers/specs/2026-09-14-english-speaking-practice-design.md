# 英文口說練習網頁 — 設計規格

## 背景與目標

使用者有一份 Excel 題庫（`app_data/1490句完整日常英文對話表.xlsx`，1490 句、6 個分類），想要一個網頁工具做英文口說練習：看中文句子、自己開口念英文、再對照正確答案與發音，並能把不熟的句子收藏起來反覆練習。

使用環境涵蓋電腦、iPhone、iPad，且使用頻率不高、更新 Excel 的頻率也低，因此優先選擇最簡單、最容易維護、跨裝置皆可直接使用的方案。

## 資料來源

Excel 檔案：`app_data/1490句完整日常英文對話表.xlsx`

分頁「英文對話總表」欄位：`編號 | 分類 | 中文句子 | 英文句子 | 練習狀態 | 備註`

6 個分類：情感表達(248)、日常生活與基本對話(250)、工作(250)、天氣氣候(248)、日常休閒(247)、健康醫療(247)

> Excel 的「練習狀態」/「備註」欄位目前不使用（不做讀寫同步），網頁的練習進度／收藏另外用獨立機制管理（見下方「我的練習題庫」）。

## 技術架構

純前端靜態網頁，無伺服器、無建置流程、無外部套件依賴：

```
English/
├── app_data/1490句完整日常英文對話表.xlsx   (原始檔，不動)
└── web/
    ├── index.html
    ├── style.css
    ├── app.js
    ├── data/sentences.json      ← 由轉換工具產生，網頁實際讀取的資料
    └── tools/convert_excel.py   ← 手動執行的 Excel → JSON 轉換工具
```

- **不做自動偵測 Excel 更新**：使用者更新 Excel 後，手動重新執行 `python3 tools/convert_excel.py` 重新產生 `data/sentences.json` 即可。
- **語音朗讀**：使用瀏覽器內建 Web Speech API (`speechSynthesis`)，設定語系為 `en-US`，免安裝、iOS Safari 可支援。
- **不做語音辨識評分**：使用者自行念、自行對照正確發音判斷，不接語音辨識 API。

### `sentences.json` 結構

```json
[
  { "id": 1, "category": "情感表達", "zh": "我今天心情非常愉快。", "en": "I'm in a wonderful mood today." },
  ...
]
```

### `convert_excel.py`

用 `openpyxl` 讀取 xlsx 的「英文對話總表」分頁（從第 2 列開始），輸出上述 JSON 陣列到 `web/data/sentences.json`。跳過編號為空的列。這是一次性/手動執行的小工具，不需要參數、不需要錯誤處理超出「檔案不存在」的基本情況。

## 分類與出題模式

- 下拉選單選項：6 個原始分類 + 「全部分類混合」 + 「我的練習題庫」。
- 選好分類後，選出題模式：
  - **照順序**：依編號遞增出題，出完最後一題回到第一題。
  - **隨機**：對目前分類的題目清單做洗牌（Fisher–Yates），依洗牌後順序出題、不重複；出完一輪後重新洗牌繼續下一輪。
- 切換分類或模式時，重新產生題目清單並從頭開始。
- 若「我的練習題庫」目前是空的，選取後顯示提示文字（例如「題庫目前是空的，請先在練習中把句子加入題庫」），不出題。

## 出題畫面與互動流程

單題卡片，直向堆疊：

1. 上方：中文句子（大字體）
2. 下方：英文句子區塊，預設用黑色色塊完全遮蓋
3. 「看結果」按鈕：點擊後
   - 移除黑色遮蓋，顯示英文句子文字
   - 自動播放一次英文發音（`speechSynthesis`）
   - 按鈕旁出現一個喇叭圖示的小按鈕，可重複點擊重新播放發音
4. 「加入/移除練習題庫」按鈕：全程顯示（不需等看答案），依目前句子是否已在收藏清單中，顯示「☆ 加入練習題庫」或「★ 已加入（點擊移除）」，點擊即切換狀態並立即存回 localStorage。
5. 「下一題」按鈕：依目前的出題模式（順序／隨機）換下一句，並重置畫面為「英文遮蓋」的初始狀態。

## 我的練習題庫（收藏清單）

- 儲存位置：瀏覽器 `localStorage`，key 例如 `englishPractice.bank`，內容為句子 id 的陣列。
- 每個裝置（電腦／iPhone／iPad）各自獨立，不自動同步。
- 提供「匯出清單」按鈕：把目前收藏的 id 陣列包成 JSON 檔（含 `exportedAt` 時間戳），觸發瀏覽器下載。
- 提供「匯入清單」按鈕（`<input type="file">`）：讀取先前匯出的 JSON 檔，把其中的 id **合併**進目前裝置的收藏清單（取聯集，不覆蓋、不刪除既有收藏）。
- 「我的練習題庫」分類選項即讀取這個 localStorage 清單，過濾出對應的句子物件。

## 響應式設計（電腦 / iPhone / iPad）

- 使用 `clamp()` 讓字體與按鈕尺寸依 viewport 寬度自動縮放。
- 所有可點擊按鈕最小高度 48px（觸控友善）。
- 版面採 Flexbox，直立窄螢幕（手機）單欄堆疊；寬螢幕（電腦/平板橫向）可視需要放寬卡片最大寬度並置中，但操作流程與元素順序不變（不做兩欄並排的複雜排版，避免不必要的複雜度）。
- 用 `<meta name="viewport" content="width=device-width, initial-scale=1">` 確保行動裝置正確縮放。

## 錯誤處理範圍

- `sentences.json` 載入失敗（例如檔案不存在）：畫面顯示簡短錯誤訊息，不嘗試自動修復或重試。
- localStorage 不可用（極少數隱私模式情況）：加入/移除題庫按鈕仍可切換畫面狀態，但重新整理後會遺失，不特別攔截或提示（超出目前範圍的 edge case）。
- 匯入的 JSON 檔格式錯誤：顯示簡短錯誤訊息，不套用匯入內容。

## 測試方式

- 用 Chrome DevTools 的裝置模擬（iPhone、iPad 尺寸）確認排版、字體與按鈕大小。
- 手動走過完整流程：選分類 → 選模式 → 看結果（含發音播放）→ 加入/移除題庫 → 下一題 → 切換到「我的練習題庫」分類驗證篩選正確 → 匯出清單 → （模擬另一裝置）匯入清單驗證合併正確。
- 執行 `convert_excel.py` 驗證能正確從 Excel 產生 `sentences.json`，筆數與分類統計與原始 Excel 一致（1490 筆、6 分類）。

## 明確排除範圍（YAGNI）

- 不做自動偵測 Excel 檔案更新。
- 不做語音辨識評分。
- 不做跨裝置雲端同步（用匯出/匯入取代）。
- 不寫回 Excel 的「練習狀態」欄位。
- 不做使用者帳號系統、不做後端伺服器。
